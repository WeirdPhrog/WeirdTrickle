# История изменений WeirdTrickle

История по версиям ведётся с перехода на `MAJOR.MINOR.PATCH`. Текущее поведение и отличия от исходного MagiTrickle описаны в [README](README.md#изменения-относительно-оригинала).

## [Unreleased]

## [2.0.2] — 2026-10-18

### Исправлено

- При обновлении подписки устаревший или неподдерживаемый сохранённый тип определяется заново по текущему содержимому списка. Поддерживаемые пользовательские типы, ID и выключенное состояние правил сохраняются; включения отключённых записей не происходит. Отброшенный тип больше не создаёт ложный конфликт нормализованных дублей.
- Повторные ошибки восстановления маршрутизации увеличивают паузу от 1 до 15 минут. Состояние ошибки сбрасывается после успешного восстановления, применения правок или отключения набора; ручное сохранение не ждёт паузы. Пока восстановление не завершено, прежняя защита с blackhole сохраняется.
- При отсутствии незавершённых восстановлений фоновая проверка обходится атомарным флагом и не берёт общий замок на запись. Здоровые наборы не пересобираются; отложенная попытка не берёт замок набора до наступления срока.

### Добавлено

- `GET /api/v1/system/routing` возвращает список наборов с незавершённым откатом: группу/подписку, причину, паузу и ближайшее разрешённое время повтора. Это состояние восстановления, а не общая проверка работоспособности VPN; в конфиг оно не сохраняется.
- WebUI показывает предупреждение «Маршрутизация приостановлена» на обеих вкладках, с именами затронутых наборов, причинами и временем повтора. Статус обновляется каждые 30 секунд в видимой вкладке и при возвращении в окно; несохранённые правки не перезагружаются. При недоступности API сохраняется последнее предупреждение с отметкой о недоступности статуса.

## [2.0.1] — 2026-10-18

### Исправлено

- Чистая установка снова запускается: из стандартных конфигов Entware и OpenWrt удалён оставшийся пример Regex. Оба поставляемых конфига проверяются настоящим загрузчиком конфигурации в CI.
- Подписки принимают начальную точку в доменном имени (`.ua` → Namespace `ua`), завершающую точку обычного домена, IDN в Unicode с преобразованием в Punycode, BOM и комментарии после `#`. Запятые внутри комментария не создают дополнительные правила. Нормализация сохраняет ID, тип и включение существующей записи; конфликтующие настройки дублей отклоняют обновление с сохранением прежнего списка.
- Пустой или состоящий только из комментариев ответ сервера больше не стирает непустую подписку. Это ошибка обновления с сохранением правил и дат, паузой повторов от 1 до 15 минут и возможностью ручной повторной синхронизации. Нераспознанные записи по-прежнему отклоняют список целиком; ошибка теперь содержит проблемную запись.
- Неудачный откат активной группы или подписки повторяется раз в минуту. Приостановленный интерфейс восстанавливается только после успешного восстановления IPv4 и IPv6; обычная правка имени не обходит эту проверку. Здоровые наборы фоновый повтор не пересобирает.
- DNS-прокси принимает ответы об ошибке без секции вопросов, включая FORMERR, NOTIMP и REFUSED, если в них нет записей ответа/авторитета и дополнительных данных, кроме EDNS. Положительные ответы и ответы с вопросами по-прежнему проверяются по исходному вопросу.
- Имена интерфейсов с запрещённым Linux символом `:` отклоняются до применения настроек. В описании Wildcard удалена ссылка на отсутствующий тип RegExp.

## [2.0.0] — 2026-10-18

### Удалено

- Тип правил Regex полностью удалён из Groups, Subscriptions и автоопределения при импорте. Удалены движок `regexp2`, кеш компиляции, обработка таймаутов и относящиеся к этому типу тесты и бенчмарки. Остаются Domain, Namespace, Wildcard, Subnet и Subnet6.
- Удалённый движок больше не участвует в DNS-обработке и пересборке ipset: тяжёлая регулярка не может вызвать `SERVFAIL`, повторяющиеся откаты или зависание интерфейса на blackhole.

### Исправлено

- API и загрузка конфигурации отклоняют включённые правила неподдерживаемого типа. Скачанный список с неподдерживаемой записью отклоняется целиком; предыдущие рабочие правила сохраняются. Такие записи не пропускаются молча с возможным уходом трафика через другой маршрут.
- Backoff подписок от 1 до 15 минут применяется и к ошибкам проверки списка и применения правил. Успешное скачивание само по себе больше не сбрасывает паузу; её сбрасывает успешная обработка. Ручная синхронизация по-прежнему выполняется сразу.
- Проверки цвета, доменных имён и Wildcard используют стандартную библиотеку Go без зависимости от удалённого движка.

### Перед обновлением с 1.x

- Это несовместимое изменение набора типов правил. Если в конфиге есть включённые Regex, перед обновлением замените их на Domain, Namespace или Wildcard либо выключите сами правила. Сервис отклоняет конфигурацию с включённым неподдерживаемым типом и сохраняет исходный файл. Конфиги без Regex не требуют преобразования, пакет и пути настроек прежние.

## [1.0.6] — 2026-10-18

### Исправлено

- WebUI отслеживает изменения правил независимо от совпадения их ID в разных группах и подписках. Синхронизация одной подписки не сбрасывает признак несохранённых правок другой; частичные обновления сохраняют корректное исходное состояние для последующего удаления. При переносе правила в группу с таким же ID переносимому правилу назначается новый ID: оба правила остаются доступны для редактирования и сохранения.
- DNS-прокси проверяет домен, тип и класс каждого вопроса, а также код операции. Запоздавший ответ для другого вопроса отбрасывается даже при совпадении ID запроса на повторно используемом соединении.
- Таймаут регулярного выражения больше не считается достоверным отсутствием совпадения: DNS-ответ получает `SERVFAIL` без адресов, а ошибка сопоставления при обновлении правил прерывает замену действующих ipset.
- API сохраняет прежнее состояние включения группы или подписки и интервал автообновления подписки, если соответствующие необязательные поля не переданы. Явные `false` и нулевой интервал по-прежнему применяются.
- API отклоняет небезопасные имена интерфейсов маршрутизации, включая пробелы, переводы строк и слишком длинные имена, до передачи в firewall.
- Настройки DNS-прокси, его upstream и HTTP-сервера принимают IPv6-адреса как в квадратных скобках, так и без них; адреса с указанием зоны также обрабатываются корректно.

## [1.0.5] — 2026-10-18

### Изменено

- Уточнена тёмная палитра WebUI: фон, панели и мятные акценты стали немного холоднее, с меньшей желтизной. Сохранены приглушённость, привычная яркость и читаемость.

## [1.0.4] — 2026-10-18

### Изменено

- Тёмная палитра WebUI получила приглушённый зелёный оттенок и мягкий мятный акцент в цвет маскота. Обновлены фон, панели, вкладки, поля, переключатели и страница входа с сохранением привычной яркости и читаемости.

## [1.0.3] — 2026-10-18

### Изменено

- Обновлён маскот: исходное изображение, логотип README, страница входа, favicon и иконка приложения используют новую версию. Сохранена прозрачность; адрес иконки изменён для обновления браузерного кеша.
- В README добавлены команды восстановления `config.yaml` из выбранного архива и пояснение о потере изменений, сделанных после создания этой копии.
- Из Makefile удалён неиспользуемый экспорт переменных старого CI и преобразование старого суффикса `~git` для APK. Существующая ручная пометка `PKG_VERSION_PRERELEASE=1` сохранена и описана отдельно от версии пакета.

## [1.0.2] — 2026-10-18

### Изменено

- README уточняет отказ запуска при ошибках конфигурации, отдельную версию схемы `configVersion`, восстановление из резервной копии и возврат с календарных выпусков. Примеры установки и создания тега используют подставляемый номер версии.
- В окне «О программе» добавлена ссылка для сообщений об ошибках WeirdTrickle; ссылки исходного MagiTrickle выделены отдельно. На низких экранах содержимое прокручивается, а заголовок и кнопка закрытия остаются доступны. В README указан тот же канал поддержки.
- История выпусков вынесена в CHANGELOG. CI проверяет наличие заметок для релизного тега и использует их как описание выпуска.
- Обновлены Swagger и инструкции для разработки: документированы настройки загрузки подписок и ответы `409 Conflict`, добавлена воспроизводимая генерация Swagger с проверкой в CI.
- Удалён неиспользуемый GitLab CI исходного проекта; комментарии о совместимости больше не привязаны к его будущему выпуску 1.0.0. В README описано существующее ограничение определения dev-сборок по версии.

## [1.0.1] — 2026-10-18

### Исправлено

- DNS-префильтр учитывает новые домены подписок при добавлении подписки и обновлении её списка. В 1.0.0 ответ для такого домена мог вернуться клиенту до применения маршрутизации, и его адрес мог не попасть в ipset до следующего DNS-запроса. Пользователям доменных правил подписок рекомендуется версия 1.0.1 или новее.
- Установщик отличает WeirdTrickle от оригинального пакета по полю `Description` и при совпадающем номере версии выполняет переустановку с сохранением конфигурации.

## [1.0.0] — 2026-10-18

### Изменено

- Проект и репозиторий переименованы в WeirdTrickle, заменён логотип. Имя пакета `magitrickle`, сервис `S99magitrickle`, бинарник `magitrickled`, Go-модуль и пути настроек сохранены для совместимости.
- Версии `MAJOR.MINOR.PATCH` задаются файлом `VERSION`; публикацию запускает только соответствующий тег `vX.Y.Z` после проверок и сборки пакетов.
- Основная команда обновления — `weirdtrickle-update`; `magitrickle-update` сохранена как совместимый псевдоним.
- Для перехода с календарных версий `2026.x.x.x` нужно один раз выполнить свежий установщик: прежний updater не понимает трёхкомпонентный номер и сообщает `Invalid release version`.

### Исправлено

- Чтение настроек DNS переведено на атомарный снимок; добавлен префильтр, позволяющий посторонним DNS-ответам не ждать пересборки ipset.
- Группа с незавершённым отключением больше не вызывает `SERVFAIL` для посторонних доменов и не роняет сервис при событиях сетевого интерфейса.
- Параллельные операции API с одной группой обнаруживают изменение исходного снимка и возвращают `409 Conflict` вместо потери чужих изменений.
- Пауза между неудачными автоматическими загрузками подписки растёт от 1 до 15 минут; ручная синхронизация её не ждёт.
- Выключенные некорректные правила не блокируют сохранение Groups; результаты проверки неизменённых правил в UI кешируются.
- Блокировка установщика перенесена в `/tmp`; при удалении пакета удаляется `magitrickle-fork.conf`.
- Если правила применены, а конфиг записать не удалось, API сообщает, что изменения действуют и не сохранены на диск.

### Известная ошибка этого выпуска

- DNS-префильтр пропускал новые домены подписок во время применения правил. Исправлено в 1.0.1.
