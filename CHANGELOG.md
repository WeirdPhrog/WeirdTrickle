# История изменений WeirdTrickle

История по версиям ведётся с перехода на `MAJOR.MINOR.PATCH`. Текущее поведение и отличия от исходного MagiTrickle описаны в [README](README.md#изменения-относительно-оригинала).

## [Unreleased]

## [1.0.5] — 2026-10-18

### Изменено

- Уточнена тёмная палитра WebUI: фон, панели и мятные акценты стали немного холоднее, с меньшей желтизной. Сохранены приглушённость, привычная яркость и читаемость.

## [1.0.4] — 2026-10-18

### Изменено

- Тёмная палитра WebUI получила приглушённый зелёный оттенок и мягкий мятный акцент в цвет маскота. Обновлены фон, панели, вкладки, поля, переключатели и страница входа с сохранением привычной яркости и читаемости.

## [1.0.3] — 2026-10-18

### Изменено

- Обновлён маскот: исходное изображение, логотип README, страница входа, favicon и иконка приложения используют новую версию. Сохранена прозрачность; адрес иконки изменён для обновления браузерного кеша.
- В README добавлены команды восстановления `config.yaml` из выбранного архива и пояснение о потере изменений, сделанных после создания этой копии.
- Из Makefile удалён неиспользуемый экспорт переменных старого CI и преобразование старого суффикса `~git` для APK. Существующая ручная пометка `PKG_VERSION_PRERELEASE=1` сохранена и описана отдельно от версии пакета.

## [1.0.2] — 2026-10-18

### Изменено

- README уточняет отказ запуска при ошибках конфигурации, отдельную версию схемы `configVersion`, восстановление из резервной копии и возврат с календарных выпусков. Примеры установки и создания тега используют подставляемый номер версии.
- В окне «О программе» добавлена ссылка для сообщений об ошибках WeirdTrickle; ссылки исходного MagiTrickle выделены отдельно. На низких экранах содержимое прокручивается, а заголовок и кнопка закрытия остаются доступны. В README указан тот же канал поддержки.
- История выпусков вынесена в CHANGELOG. CI проверяет наличие заметок для релизного тега и использует их как описание выпуска.
- Обновлены Swagger и инструкции для разработки: документированы настройки загрузки подписок и ответы `409 Conflict`, добавлена воспроизводимая генерация Swagger с проверкой в CI.
- Удалён неиспользуемый GitLab CI исходного проекта; комментарии о совместимости больше не привязаны к его будущему выпуску 1.0.0. В README описано существующее ограничение определения dev-сборок по версии.

## [1.0.1] — 2026-10-18

### Исправлено

- DNS-префильтр учитывает новые домены подписок при добавлении подписки и обновлении её списка. В 1.0.0 ответ для такого домена мог вернуться клиенту до применения маршрутизации, и его адрес мог не попасть в ipset до следующего DNS-запроса. Пользователям доменных правил подписок рекомендуется версия 1.0.1 или новее.
- Установщик отличает WeirdTrickle от оригинального пакета по полю `Description` и при совпадающем номере версии выполняет переустановку с сохранением конфигурации.

## [1.0.0] — 2026-10-18

### Изменено

- Проект и репозиторий переименованы в WeirdTrickle, заменён логотип. Имя пакета `magitrickle`, сервис `S99magitrickle`, бинарник `magitrickled`, Go-модуль и пути настроек сохранены для совместимости.
- Версии `MAJOR.MINOR.PATCH` задаются файлом `VERSION`; публикацию запускает только соответствующий тег `vX.Y.Z` после проверок и сборки пакетов.
- Основная команда обновления — `weirdtrickle-update`; `magitrickle-update` сохранена как совместимый псевдоним.
- Для перехода с календарных версий `2026.x.x.x` нужно один раз выполнить свежий установщик: прежний updater не понимает трёхкомпонентный номер и сообщает `Invalid release version`.

### Исправлено

- Чтение настроек DNS переведено на атомарный снимок; добавлен префильтр, позволяющий посторонним DNS-ответам не ждать пересборки ipset.
- Группа с незавершённым отключением больше не вызывает `SERVFAIL` для посторонних доменов и не роняет сервис при событиях сетевого интерфейса.
- Параллельные операции API с одной группой обнаруживают изменение исходного снимка и возвращают `409 Conflict` вместо потери чужих изменений.
- Пауза между неудачными автоматическими загрузками подписки растёт от 1 до 15 минут; ручная синхронизация её не ждёт.
- Выключенные некорректные правила не блокируют сохранение Groups; результаты проверки неизменённых правил в UI кешируются.
- Блокировка установщика перенесена в `/tmp`; при удалении пакета удаляется `magitrickle-fork.conf`.
- Если правила применены, а конфиг записать не удалось, API сообщает, что изменения действуют и не сохранены на диск.

### Известная ошибка этого выпуска

- DNS-префильтр пропускал новые домены подписок во время применения правил. Исправлено в 1.0.1.
